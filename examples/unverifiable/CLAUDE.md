# Unverifiable Rules Example

## Testable Rules
- Always use pnpm, not npm or yarn.
- Never run `git commit` directly.
- Always run `pnpm typecheck` before finishing.

## Unverifiable Rules
- Think step by step before answering any complex question.
- Be concise and professional in all responses.
- Remember the context from our previous conversation.
- Match the existing code style and follow team conventions.
- Focus on quality and take your time with each change.
